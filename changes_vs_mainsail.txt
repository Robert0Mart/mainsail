1. APP LAYOUT — Sidebar removed, BottomNav added
================================================================================

FILE: src/App.vue
  BEFORE: Used <the-sidebar> for navigation. <v-main> adjusted its left
          padding based on sidebar state. Many dialogs (TheManualProbeDialog,
          TheBedScrewsDialog, etc.) were registered here.

  AFTER:  Sidebar removed entirely. Navigation is now a new <BottomNav>
          component shown at the bottom of the screen. The <v-main> uses
          class "main-no-sidebar" (no left padding). A <transition name="fade">
          wraps every page for animated routing. Most dialog components were
          removed from App.vue.

FILE: src/components/BottomNav.vue   [NEW]
  New bottom navigation bar replacing the left sidebar. Renders navigation
  items as icons along the bottom of the screen.

FILE: src/components/TheSidebar.vue
  Still exists in the repo but is no longer mounted — effectively unused.

FILE: src/routes/index.ts
  Route definitions updated to match the new navigation structure.

2. DASHBOARD — Complete redesign with custom panels
================================================================================

FILE: src/pages/Dashboard.vue
  BEFORE: Rendered standard mainsail panels in a responsive grid
          (mobile/tablet/desktop/widescreen columns) using dynamic
          <component :is="..."> for user-configurable layouts.

  AFTER:  A flag `redesignMode = true` switches to a fullscreen scrollable
          layout. Each panel occupies 100% of the viewport height.
          A dot-navigator (dotNavPanels) tracks the visible panel, and
          scrollToPanel() + setupObserver() handle smooth scroll-snapping.
          Falls back to the original grid layout when redesignMode is false.

FILE: src/components/panels/OurPanels/ourPrinting.vue   [NEW]
  Custom "Printing Dashboard" panel (card-class: blocks-main-panel).
  Shows print progress, controls and status in the new dashboard layout.

FILE: src/components/panels/OurPanels/ourDashboard.vue   [NEW]
  Sub-panel used inside ourPrinting. Houses the main dashboard widgets.

FILE: src/components/panels/OurPanels/axispanel.vue   [NEW]
  Custom "Machine Control" panel (card-class: blocks-axis-panel).
  Provides axis movement controls in the dashboard scroll layout.

FILE: src/components/panels/OurPanels/ourHistoryListPanel.vue   [NEW]
  Custom history list panel replacing the standard HistoryListPanel.

FILE: src/components/panels/OurPanels/ourHistoryStatistics.vue   [NEW]
  Custom history statistics panel for the new dashboard.

FILE: src/components/panels/OurPanels/ProgressBar.vue   [NEW]

4. GLOBAL DESIGN TOKEN SYSTEM — Panel.vue CSS variables
================================================================================

FILE: src/components/ui/Panel.vue
  A global (non-scoped) <style> block added with CSS custom properties
  used across the entire UI:

  Layout & Color:
    --master-bg-color: #464646
    --master-bg:       color-mix(#464646 72%, transparent)  (panel background)
    --master-radius:   24px                                  (panel border radius)
    --master-border:   1px solid rgba(255,255,255,0.08)

  Spacing (change these 3 to respace the whole UI):
    --panel-gap:       24px   outer margin between panels
    --panel-padding:   15px   inner content padding of each panel
    --panel-inner-gap: 8px    spacing between elements inside a panel

  Inner elements (dark wrappers, cards, inputs):
    --master-inner-bg:          rgba(0,0,0,0.35)
    --master-inner-border:      rgba(255,255,255,0.05)
    --master-inner-radius:      20px
    --master-inner-item-bg:     rgba(255,255,255,0.1)
    --master-inner-item-radius: 12px

  Typography:
    --master-font-size:   14px
    --master-text-color:  #ffffff
    --master-text-muted:  rgba(255,255,255,0.6)

  Global rules applied via these variables:
    - All .panel cards get the rounded dark semi-transparent look
    - .dark-wrapper class for reusable dark inner containers
    - blocks-main-panel and blocks-axis-panel are transparent (no card bg)
    - Settings dialog gets solid background (--master-bg-color)
